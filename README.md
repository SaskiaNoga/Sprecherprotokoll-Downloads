# Sprecherprotokoll vorbereiten – Downloads

Dieses Repository dient ausschließlich der Verteilung freigegebener Programmdateien von „Sprecherprotokoll vorbereiten“. Es enthält keinen Quellcode.

## Aktuelle Version herunterladen

- **macOS:** [Sprecherprotokoll-macOS.dmg](https://github.com/SaskiaNoga/Sprecherprotokoll-Downloads/releases/latest/download/Sprecherprotokoll-macOS.dmg) – öffnen und „Sprecherprotokoll vorbereiten“ auf „Programme“ ziehen
- **Windows:** [Sprecherprotokoll-Windows.exe](https://github.com/SaskiaNoga/Sprecherprotokoll-Downloads/releases/latest/download/Sprecherprotokoll-Windows.exe) – speichern und per Doppelklick starten

Ab Version 3.5.0 erkennt die Anwendung neue Versionen selbst und installiert sie nach Ihrer Zustimmung.

Zu jedem Release gehören `SHA256.txt` (Prüfsummen) und `update.json`. Das sind signierte Update-Informationen, die die Anwendung vor jeder Installation prüft.
